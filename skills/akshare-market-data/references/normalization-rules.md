# Normalization Rules

AkShare often returns pandas DataFrames with source-specific column names. Normalize them before using the data in prompts.

## General Rules

- Coerce DataFrames into a list of records.
- Detect symbol and name columns heuristically.
- Detect price and percent-change columns heuristically.
- Return ISO timestamps generated by the wrapper when the source does not include one.
- Keep the payload small enough for prompt injection or state storage.

## Preferred Canonical Fields

- `label`
- `value`
- `unit`
- `timestamp`
- `source`
- `components`
- `leaders`
- `quotes`

## Heuristic Column Priorities

### Symbol-like

- `symbol`
- `代码`
- `编号`

### Name-like

- `name`
- `名称`

### Price-like

- `latest`
- `price`
- `最新价`
- `现价`

### Percent change-like

- `pct_chg`
- `change_percent`
- `涨跌幅`
- `涨幅`

## Mode Expectations

### `watchlist_quote`

- Filter rows by requested symbols or names.
- Return a small `quotes` array with symbol, name, price, and percent change.

### `futures_quote`

- Normalize like `watchlist_quote` but preserve contract names and treat the label as futures-specific.

### `fx_quote`

- For `fx_spot_quote`, map `货币对` into both symbol and name.
- Use the midpoint of `买报价` and `卖报价` as price when both are available.
- Percent change is usually unavailable, so omit it.

## Failure Handling

- If the dataset is unsupported, return `status: error`.
- If the DataFrame is empty, return `status: empty`.
- If required columns cannot be inferred for the requested mode, return `status: error` with a short explanation.
